# 실사례 각색 경보 (scenarios)

최근 3개월(2026년 8~11월)에 보고된 실제 보안 사건을 **모티브로 각색한 합성 경보**입니다. 우리 XDR이 이런 성격의 사건을 실제로 잡아내는지 점검하는 데 씁니다(스텝 8).

## 원칙

- **합성 경보입니다.** 실제 악성 코드·페이로드·침해 지표(IOC)를 그대로 싣지 않습니다. 도메인·주소는 문서용 대역(192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24)과 사설 대역으로, 키·해시·CLSID 같은 식별자는 `<hash>` 등으로 중립화했습니다.
- **각 경보는 우리 경보 형식(`aleph.xdr.fixture`)과 호환**됩니다. 판정기·집행기는 `id`·`rule`·`data`만 보고, `_`로 시작하는 메타 필드(`_source`·`_adaptation`·`_expect`)는 무시합니다.
- **각색 근거를 명시**합니다. 각 경보에 모티브 사건(`_source`)과 어떻게 각색했는지(`_adaptation`), 기대 판정(`_expect`)을 답니다.
- **원본 자산(`aleph-source/`)은 건드리지 않습니다.** 각색 경보는 이 폴더에만 둡니다.

## 모듈별 모티브 사건

| 파일 | 모듈 | 모티브 사건 | 시점 |
|---|---|---|---|
| `brute-force.json` | 무차별 로그인 | 덴마크 중앙인명등록 — 약한 암호 계정 악용 | 2026-10-12 |
| `web-injection.json` | 웹 주입 | Convertr — 변조 분석 스크립트로 카드정보 스키밍 | 2026-10-27 |
| `known-cve.json` | 알려진 취약점 | BeyondTrust Remote Support — 제로데이 CVE-2026-102764 | 2026-10 |
| `persistence.json` | 지속성 | 레벨 인피니트/니케 PC 런처 — 크롬 폴더 DLL·CLSID | 2026-09~11 |
| `privilege.json` | 권한 상승 | LiteLLM — 노출 마스터키로 권한 있는 토큰 획득 | 2026-05~10 |
| `exfiltration.json` | 자료 반출 | Ledger 하드월렛 — 복구 정보 탈취 | 2026-10-14 |

## 한계 메모

- `known-cve` 모듈의 탐지는 **원격 조회 구문(Log4Shell류) 시그니처**가 중심입니다. BeyondTrust CVE는 성격이 다르지만, 이 모듈이 잡을 수 있도록 **공개 악용 요청이 원격 조회 구문 형태를 띤 국면**으로 각색했습니다. 조회 구문이 아닌 CVE는 시그니처 추가가 필요합니다(스텝 8 보고서에 기록).
- `brute-force`의 덴마크 사건은 실제로는 약한 암호로 로그인에 **성공**했으나, 탐지 가능한 **반복 실패 선행** 국면으로 각색했습니다.
